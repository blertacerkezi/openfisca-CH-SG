# KiBG Frontend

Fragebogen für das Kinderbetreuungsgesetz des Kantons St. Gallen.

Liegt im Repo neben dem Python-Paket:

```text
openfisca-CH-SG/
├── openfisca_ch_sg/
└── frontend/          ← dieser Ordner
    ├── package.json
    ├── vite.config.ts
    ├── tsconfig.json
    └── src/
```

## Start

Node 22 (oder 20.19+).

```bash
cd frontend
npm install
npm run dev
```

Dann http://localhost:3000 öffnen.
